# Replit Build Prompt: Real Estate CRM

## Project Overview

**Product Name:** PropertyFlow (Real Estate CRM)

**One-line Description:** A simple but powerful real estate CRM that helps small teams never lose leads, track deals from inquiry to closure, manage properties, and see real-time business metrics.

**Business Context:** 
- 2-5 person real estate team
- Manage all property types (Residential, Commercial, Rental, Land)
- Currently using WhatsApp, Excel, Paper — everything scattered
- Pain points: Leads falling through cracks, no pipeline visibility, duplicate records, no reporting

**Three User Roles:**
1. **Sales Agent** (Rajesh) — Captures leads, shows properties, follows up, closes deals
2. **Team Lead** (Priya) — Manages agents, assigns leads, coaches, reports to owner
3. **Business Owner** (Vikram) — Wants dashboards and revenue metrics

## Design System (Neo-Brutalist)

### Color Palette
```
Primary Yellow:    #ffe17c  (hero actions, highlights, important badges)
Charcoal Dark:     #171e19  (navigation, dark sections, text)
Sage Accent:       #b7c6c2  (secondary buttons, muted info, disabled states)
White:             #ffffff  (cards, modals, content areas)
Black:             #000000  (text, borders, shadows, all icons)
Red Alert:         #ff4444  (overdue, at-risk, urgent statuses)
Green Success:     #22c55e  (closed deals, completed tasks, healthy status)
Yellow Warning:    #eab308  (at-risk, stalled deals, requires attention)
Blue Info:         #3b82f6  (informational badges, secondary highlights)
Gray:              #9ca3af  (disabled, inactive, secondary text)
```

### Typography
```
Headings:    Cabinet Grotesk, Weight 800 (Extrabold)
             Letter-spacing: tighter (tracking-tighter in Tailwind)
             Used for: Screen titles, section headers, dashboard metrics

Body Text:   Satoshi, Weight 500 (Medium)
             Used for: Task descriptions, client names, property details, general content

Buttons:     Satoshi, Weight 700 (Bold)
             Used for: All clickable buttons, CTAs

Labels:      Satoshi, Weight 500 (Medium)
             Used for: Field labels, badges, tags

Small Text:  Satoshi, Weight 400 (Regular)
             Used for: Timestamps, helper text, secondary info
```

```

No shadow
Padding: 12px 16px

**Status Badge:**
```
Pill-shaped with 2px border
Padding: 6px 12px
Font: Satoshi Bold 12px
Examples:
  - Inquiry: #ffffff bg, #000000 border, black text
  - Site Visit: #ffe17c bg, #000000 border, black text

**Yellow Background Pattern:**
- 32px × 32px radial dot grid
- Opacity: 10%
- Applied to all #ffe17c backgrounds
- Creates subtle texture without distraction

```
Red card borders for at-risk/overdue items

Green checkmarks for completed items

## API Endpoints

### Authentication
```
POST /api/auth/signup
  { name, phone, email, password, is_owner, org_name }
  → { user, token, org }

POST /api/auth/send-otp
  { phone }
  → { message, expires_in }

POST /api/auth/verify-otp
  { phone, otp }
  → { user, token, org }

POST /api/auth/login
  { phone, password }
  → { user, token, org }

POST /api/auth/logout
  → { message }
```

### Clients/Leads
```
POST /api/clients
  { name, phone, email, client_type, budget_min, budget_max, property_type_interested, source }
  → { client }

GET /api/clients
  ?status=inquiry&assigned_to=rajesh&search=amit
  → { clients[], total_count }

GET /api/clients/:id
  → { client, activities[], deals[], follow_ups[] }

PUT /api/clients/:id
  { name, phone, status, assigned_to, notes }
  → { client }

GET /api/clients/duplicates/check
  ?phone=9876543210&name=amit
  → { possible_duplicates[] }

POST /api/clients/:id/merge
  { merge_with_client_id }
  → { merged_client }
```

### Properties
```
POST /api/properties
  { address, area, city, property_type, bedrooms, bathrooms, price, status, description, amenities }
  → { property }

GET /api/properties
  ?type=residential&status=available&city=bangalore&min_price=20&max_price=50
  → { properties[], total_count }

GET /api/properties/:id
  → { property, images[], recent_showings[] }

PUT /api/properties/:id
  { price, status, description, amenities }
  → { property }

POST /api/properties/:id/images
  { images: [file, file] }
  → { property_images[] }

DELETE /api/properties/:id/images/:image_id
  → { message }
```

### Deals
```
POST /api/deals
  { client_id, property_id, offer_price, commission_rate, expected_closing_date }
  → { deal }

GET /api/deals
  ?status=negotiation&agent_id=rajesh
  → { deals[], total_count, total_pipeline_value }

GET /api/deals/:id
  → { deal, client, property, activities[] }

PUT /api/deals/:id
  { status, offer_price, commission_status, commission_paid_amount }
  → { deal }

GET /api/deals/pipeline/summary
  → { inquiry_count, site_visit_count, negotiation_count, offer_count, closed_count }
```

### Activities/Timeline
```
POST /api/activities
  { client_id, property_id, activity_type, description }
  → { activity }

GET /api/clients/:id/activities
  → { activities[] }
```

### Follow-ups & Tasks
```
POST /api/follow-ups
  { client_id, follow_up_type, follow_up_date, follow_up_time, notes, assigned_to }
  → { follow_up }

GET /api/follow-ups
  ?status=pending&assigned_to=current_user&date_from=2024-03-15

PUT /api/follow-ups/:id
  { status, snooze_until_date }
  → { follow_up }

POST /api/tasks
  { title, task_type, assigned_to, client_id, property_id, due_date, priority }

GET /api/tasks

## Tech Stack Recommendations

**Backend:**
- Node.js + Express.js
- Database: PostgreSQL (better for complex queries)
- Redis for caching, notifications
- JWT authentication

**Frontend:**
- React.js for web
- React Native for mobile (or use React Native Web for both)
- Tailwind CSS + Custom CSS for Neo-Brutalist styling
- Redux or Zustand for state management
- React Query for API data fetching

**Real-time:**
- Socket.io for live notifications, real-time updates
- Firebase Cloud Messaging for push notifications

**Deployment:**
- Backend: Heroku, Railway, or AWS
- Database: PostgreSQL on AWS RDS or Heroku Postgres
- Frontend: Vercel or Netlify
- Storage: AWS S3 for property photos
